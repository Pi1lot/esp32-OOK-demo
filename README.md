* Plug a wire to the 25 GPIO on the ESP32
* Upload `emitter.ino` to the ESP32
* Run the `decode.py` with a RTL-SDR reciever plugged in your computer
* Message `HELLO` should appear in your terminal.
* One could run the `ook_rx_visual_decode_gnu_radio.grc` in GNU Radio to get a more visual demo. It provides the ASCII decoder.
